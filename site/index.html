Archived local-AI tool

A simple runner for local Ollama models.

ai-runner provided a guided command-line path for choosing, pulling and prompting local models. It is retained as a reference while its reusable runtime behavior moves into the shared tooling.

Archive status. For current shell integration, use script-helpers and its Ollama helpers. For broader local-AI learning and projects, start with NikOS and local-ai-lab.
